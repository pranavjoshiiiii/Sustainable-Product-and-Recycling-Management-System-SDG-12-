# Sustainable-Product-and-Recycling-Management-System-SDG-12-
Project Description

The Sustainable Recycling System is an application that helps users make better decisions about waste. It provides simple information about products, such as how long they last, how they can be reused, and how to dispose of them properly. The system also tracks the user’s actions to show their impact on the environment and encourage more sustainable habits.

Purpose of system:-
	•	Help users understand how to dispose of and reuse products correctly
	•	Reduce environmental waste by encouraging sustainable habits
	•	Provide useful information about product lifecycle and recycling methods
	•	Allow users to track their personal contribution to saving the environment
